# Lyns

Веб-чат для личного общения между пользователями. Сначала — удобная работа в браузере телефона, затем развитие возможностей на компьютере. Вход в первой версии — по электронной почте и паролю.

## Текущий этап: прототип

Уже можно выбрать демонстрационную переписку, найти собеседника по имени, написать сообщение и переключиться между диалогами. Черновики сохраняются при переключении диалогов в открытой вкладке. На узком экране список и диалог открываются отдельно.

Все данные сейчас демонстрационные и хранятся в памяти вкладки. Обновление страницы сбрасывает сообщения и черновики. Отправка не доставляет сообщения другим пользователям. Регистрация, серверное хранение и подтверждение почты ещё не реализованы.

## Языки и инструменты

| Инструмент | Назначение | Состояние |
| --- | --- | --- |
| TypeScript | Интерфейс и серверная логика | Используется |
| React + Next.js App Router | Страницы и компоненты; в дальнейшем HTTP API | Используется для интерфейса |
| CSS | Адаптивное оформление | Используется |
| PostgreSQL + SQL | Пользователи, сессии, переписки, сообщения | Запланировано |

Один основной язык позволит совместно использовать типы и не поддерживать отдельный сервер на другом языке. PostgreSQL выбран для связей между пользователями, участниками диалогов и сообщениями. ORM и библиотеку аутентификации выберем перед подключением базы.

## Быстрый запуск

Требуются Node.js 24 и npm. Выполните из каталога репозитория:

```sh
npm ci
npm run dev -- --hostname 0.0.0.0
```

Сервер слушает порт 3000. В текущей облачной среде при недоступном домашнем каталоге задавайте `npm_config_cache=/workspace/.npm-cache` перед командами установки. Для прототипа база данных, ключи и переменные окружения не нужны.

## Проверки и production-запуск

```sh
npm run lint
npx --no-install tsc --noEmit
npm run build
npm start -- --hostname 0.0.0.0
```

Перед production-запуском остановите dev-сервер, если он использует тот же порт. После чистой установки первый запуск Next.js или сборка создаёт необходимые типы маршрутов.

Ручные сценарии проверки описаны в [прототипе](docs/PROTOTYPE.md). Проверены сборка, типы, линтер, поиск, отправка локального сообщения, изоляция диалогов и мобильная навигация. Автоматизированного набора тестов в репозитории пока нет.

